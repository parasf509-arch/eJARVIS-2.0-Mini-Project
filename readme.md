
# eJARVIS 2.0 - Smart Personal Voice Assistant

## About
eJARVIS 2.0 is a Python-based desktop voice assistant
that allows users to interact using voice commands
and text input.

## Features
- Desktop GUI using Tkinter
- Voice recognition
- Text-to-speech responses
- Hindi and English recognition attempts
- Open websites
- Google and YouTube search
- Date and time information
- Calculator
- Wikipedia search
- Open Windows applications

## Technologies
- Python
- Tkinter
- SpeechRecognition
- PyAudio
- pyttsx3
- Wikipedia

## Installation

1. Clone or download this repository.
2. Open the project folder in Command Prompt.
3. Create a virtual environment:

   python -m venv venv

4. Activate it:

   venv\Scripts\activate

5. Install dependencies:

   pip install -r requirements.txt

6. Run:

   python main.py

## Note
Internet is required for online speech recognition,
Google searches and Wikipedia.
